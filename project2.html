USB-C Power Board for a MicroMouse

A populated PCB built as the power board for the MicroMouse.

More about it

A custom power board centred on a USB-C input, populated with motor drivers, voltage regulators, and a header for programming/debug access.

  • Decided which components would best fit the project requirements.
  • Designed the board in KiCad and ordered it through JLCPCB.
  • Performend Acceptance Test Procedures using multimeters and oscilloscopes, debugging and fixing traces where necessary to ensure PCB functioned as designed..
  • Integrated the board with the rest of the MicroMouse.
